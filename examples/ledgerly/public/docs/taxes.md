# Taxes

Set your tax rates once in **Settings → Taxes**, then pick one per line item.

- Add as many rates as you need, for example `VAT 20%` or `Sales tax 8.5%`.
- A line item without a rate is not taxed.
- Prices can be tax-inclusive or tax-exclusive. Set this per invoice. The default is exclusive.
- Totals show tax per rate, so your client can see exactly what they paid.

Ledgerly does not file or remit taxes for you. Export a tax summary from **Reports → Tax** for your accountant.
