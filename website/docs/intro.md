Embed a docs chat agent in your app. You give it your documentation (markdown and URLs) and an OpenAI-compatible host and key. It gives you a secure agent endpoint and a React chat UI that answers from your docs and shows its sources.

```
npm i sideagent
```

- [Server](./server.md): `createAgent` and framework handlers.
- [Client](./client.md): the `AgentChat` component and docked sidebar.
- [Knowledge](./knowledge.md): the documentation the agent answers from.
- [Theming](./theming.md), [History](./history.md).
- [Example](./example.md): a runnable app with a mock LLM, no API key needed.
