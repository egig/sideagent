Embed a chat agent in your app. You give it an OpenAPI spec and an OpenAI-compatible host and key. It gives you a secure agent endpoint and a React chat UI.

```
npm i sideagent
```

- [Server](./server.md): `createAgent` and framework handlers.
- [Client](./client.md): the `AgentChat` component and docked sidebar.
- [Theming](./theming.md), [History](./history.md), [Knowledge](./knowledge.md).
- [Example](./example.md): a runnable app with a mock LLM, no API key needed.
